## 1. What is BobaQuote?

BobaQuote is a free web application for creating quote graphics. It allows you to design text quotes on attractive backgrounds and download them as image files — for social media, blogs, presentations, or personal projects.

**What makes it special:**

- No installation required — runs directly in your browser
- Free to use without registration
- All editing takes place locally on your device
- No data is transferred to third-party servers
- Works on smartphones and tablets

---

## 2. Getting Started

When you open BobaQuote, you will see an interface divided into three areas:

| Area | Description |
|---|---|
| **Left Sidebar** | Navigation between the different tool sections |
| **Center Panel** | Settings and options for the selected section |
| **Right Area** | Real-time preview of your quote graphic |

The preview updates automatically whenever you make changes, allowing you to see the result instantly.

---

## 3. Section: Text & Quotes

This section is opened by default and serves as the starting point for every graphic.

### Enter a Quote

Use the **Quote** text field to enter your desired text. Line breaks are supported — simply press Enter to start a new line.

### Enter the Author

In the **Author / Source** field, you can enter the author's name, source, or year. This field is optional — if left empty, no author information will be displayed.

### Author Prefix

Use the dropdown menu to define how the author should be displayed:

| Option | Display |
|---|---|
| `— Author` | — Sven Owsianowski |
| `Without Prefix` | Sven Owsianowski |
| `© Author` | © Sven Owsianowski |
| `Source: Author` | Source: Sven Owsianowski |

### Random Quote

Click the **🎲 Random Quote** button to load a random quote from the integrated quote database. All included quotes are either in the public domain or written by the developer and may therefore be used without concern.

> **Tip:** Use a random quote as a starting point and customize it to your own needs.

## 4. Section: Background

This section allows you to define the appearance of your graphic's background. Three modes are available.

### Mode: Gradient

In gradient mode, you can choose from predefined color combinations or create your own custom gradient.

**Presets:**  
Click one of the colored squares to apply a predefined gradient.

**Custom Gradient:**  
Choose two colors using the color pickers or enter HEX color values directly (e.g., `#FF7A00`). The **Random Colors** button generates two random colors automatically.

**Gradient Type:**  
Use the dropdown menu to select the gradient style:

- Linear diagonal, horizontal, or vertical
- Radial (center outward)
- Mirrored (A → B → A)
- Split (hard transition)

### Mode: Solid Color

Select a single background color using the color picker or by entering a HEX color value.

### Mode: Image

You can use a background image in two different ways:

**Upload Your Own Image:**  
Click **Choose Local Image** and select an image from your device. The image is never uploaded and remains entirely within your browser.

**Use the Gallery:**  
BobaQuote provides a collection of ready-made background images. When opening the gallery for the first time, a notice will inform you that the images are loaded from the servers of bobaro.de. Click **Load Gallery** to display the images and select one with a click.

> **Privacy Notice:** Your own images are never uploaded to a server. All processing takes place locally in your browser.

### Effects

Below the background modes, you will find effects available for all modes:

| Setting | Description |
|---|---|
| **Overlay** | Applies a dark or light layer over the background |
| **Opacity** | Strength of the overlay (0–80%) |
| **Brightness** | Image mode only — makes the image brighter or darker |
| **Contrast** | Image mode only — increases or decreases contrast |
| **Blur** | Image mode only — softens the background image |
| **Grayscale** | Image mode only — converts the image to black and white |
| **Sepia** | Image mode only — gives the image a warm brown tone |

## 5. Section: Text Style

Customize the appearance of your text.

| Setting | Description |
|---|---|
| **Font** | Selection of locally available system fonts (no Google Fonts) |
| **Text Color** | Color of the quote text |
| **Author Color** | Color of the author name |
| **Font Weight** | Normal, Bold, Extra Bold, Heavy |
| **Letter Spacing** | Space between individual letters |
| **Text Shadow** | Strength of the shadow behind the text |
| **Text Alignment** | Left, Center, or Right |

> **Note:** Only locally available system fonts are used. No data is transferred to external font services such as Google Fonts.

## 6. Section: Watermark

A watermark is a semi-transparent text layer placed over the graphic — for example, your name or website.

| Setting | Description |
|---|---|
| **Toggle** | Show or hide the watermark |
| **Text** | Any text used as a watermark |
| **Color** | Watermark text color |
| **Size** | Font size of the watermark |
| **Opacity** | Transparency level (lower values make it less visible) |
| **Position** | Placement in corners or diagonally across the center |

## 9. Image Adjustments

Below the preview, you will find four additional settings:

| Setting | Description |
|---|---|
| **Text Size** | Font size of the quote text (28–160 px) |
| **Line Height** | Spacing between text lines |
| **Author Position** | Alignment of the author name (Left, Center, Right) |
| **Auto-Fit** | Automatically adjusts font size to fit the available space |

> **Tip:** Enable **Auto-Fit** when using longer quotes. The font size will be reduced automatically to ensure everything fits within the graphic.

## 10. Export

Once your graphic is complete, you can download it.

| Button | Format | Description |
|---|---|---|
| **⬇ PNG** | PNG | Lossless quality, ideal for text and sharp graphics |
| **⬇ JPEG** | JPEG | Smaller file size, suitable for photographs |

The filename is generated automatically and includes the application name, image size, and creation date:

```text
bobaquote-1080x1080-15-06-2026.png
```

The file will be saved directly to your download folder.

## 13. Privacy & Cookies

BobaQuote was developed with a strong focus on privacy.

- **No cookie banner required** — no tracking cookies are used
- **No data sharing** — uploaded images and entered texts never leave your browser
- **Local storage only** — only theme preferences (dark/light) and gallery consent are stored locally using `localStorage`
- **CDN** — Bootstrap is loaded via jsDelivr. Due to technical requirements, your IP address is transmitted to jsDelivr. This is documented in the privacy policy.
- **Gallery** — loading the image gallery establishes a connection to bobaro.de. You will be informed beforehand and can decide whether to use the gallery.

## 14. Frequently Asked Questions (FAQ)

**Are my images uploaded to a server?**  
No. Your own images are processed exclusively within your browser and are never stored or transmitted.

**Does BobaQuote cost anything?**  
No. BobaQuote is completely free to use and does not require registration.

**Can I use BobaQuote on a smartphone?**  
Yes. BobaQuote is fully responsive and works on smartphones and tablets.

**May I use the generated graphics commercially?**  
Yes — provided you use your own text content. For quotes from the integrated database, please respect the applicable copyrights. All included quotes are either public domain or written by the developer.

**Why don't I see a cookie banner?**  
BobaQuote does not use tracking cookies and therefore does not require a cookie banner. Only technically necessary settings are stored locally.

**What happens if I reload the page?**  
All entries and settings are lost because there is no automatic save feature. Export your graphic before reloading the page.

**Which browsers are supported?**  
BobaQuote works in all modern browsers, including Chrome, Firefox, Edge, and Safari. For image exports using the blur effect, Chrome or Firefox are recommended.
